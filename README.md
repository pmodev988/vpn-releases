## English

For Windows 10/11 64-bit PCs with AMD or Intel processors. ARM64, 32-bit Windows and Windows Server are not supported.

Run the installer, allow administrator access and select “安装 / 升级 / 修复” (Install / Upgrade / Repair). Then connect using the email address and password of an account with VPN access.

You can start an upgrade while the client is running. After confirmation, the installer disconnects the VPN, closes the old client and preserves your settings. Reopen the client and reconnect when finished. Launching again displays the existing window.

This is a self-signed trial version. Windows may display an unknown-publisher warning. The public certificate and SHA-256 checksums above let you verify the downloaded files.
