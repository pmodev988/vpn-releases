## 日本語

Windows 10／11 64 bit（AMD／Intel）に対応します。ARM64、32 bit Windows、Windows Server は対象外です。

インストーラーを実行し、管理者権限を許可してインストール・更新・修復を選んでください。完了後、VPN 利用登録済みのメールアドレスとパスワードでログインします。更新の確認後は VPN が切断されます。設定は保持され、完了後に再接続できます。

自己署名証明書を使用しているため、Windows が発行元の警告を表示する場合があります。上記の証明書とチェックサムでファイルを確認できます。

## English

For Windows 10/11 64-bit PCs with AMD or Intel processors. ARM64, 32-bit Windows and Windows Server are not supported.

Run the installer, allow administrator access, and choose install, upgrade or repair. Sign in with an account that has VPN access. An upgrade disconnects the VPN after confirmation and preserves your settings. Reconnect when it finishes.

The installer uses a self-signed certificate; Windows may display an unknown-publisher warning. Use the public certificate and checksums above to verify the files.
